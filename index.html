Prioritas Pemeriksaan Objek Reklame

Daftar objek diurutkan secara deterministik untuk membantu analis merencanakan verifikasi lapangan.

info Dasar Logika Prioritas Deterministik (PRD Bab 9)

Urutan antrean peninjauan diturunkan secara transparan tanpa klaim bobot risiko resmi:
1. Kategori Prioritas: Tinggi (Masalah struktur: ID kosong / ID duplikat / ≥3 anomali) > Sedang (Kualitas atribut esensial / kandidat duplikat) > Perlu Ditinjau (Koordinat belum ada / status administrasi kosong).
2. Deterministik Seri: Jika dua objek memiliki kategori sama, diurutkan berdasarkan jumlah aturan pemicu terbanyak, lalu ID objek alfabetis.
